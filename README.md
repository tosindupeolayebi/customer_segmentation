Customer Segmentation Predictor

A machine learning project that predicts which of four customer segments (A, B, C or D) a customer belongs to.

What it does
- Cleans a dataset of about 10,700 customers (fills missing values)
- Explores the data with charts, such as spending score by segment
- Trains two models: logistic regression and a decision tree
- Predicts the segment for a new customer

Results
- Logistic regression: about 46% accuracy
- Decision tree: about 50% accuracy

Tech
Python, Pandas, Scikit-learn, Seaborn, Jupyter Notebook

Files
- `ml8_customer_segmentation_prediction.ipynb`: logistic regression
- `ml9_customer_prediction_using_decision_tree.ipynb`: decision tree
- `Customer Segmentation.csv`: the dataset
